# Aks Rooh 🌙✨

**A private soul-garden journal** — a calm, nocturnal space for personal reflections, mood tracking, and gentle AI-powered insights.

> *"A quiet moment for you. Leave a thought, a feeling, or a small moment exactly as it is."*

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| 📓 **Journal** | Write daily reflections with mood tracking (1–5 scale) |
| 📊 **Insights** | Personalised mood analytics, trend visualisation, recurring themes, word frequency, and context-aware suggestions |
| 🌱 **Soul Garden** | A visual garden that grows with every reflection — trees, fireflies, and emoji flowers |
| 🤖 **AI Companion** | Optional AI-powered poetic responses to your reflections (via OpenAI) |
| 🔒 **Private** | All data stored locally in SQLite. Password hashed with bcrypt. JWT-authenticated API |

## 🚀 Quick Start

### Prerequisites
- **Node.js** 18+
- **npm** 9+

### 1. Clone & Install

```bash
# Install backend dependencies
cd backend
npm install

# Install frontend dependencies
cd ../frontend
npm install
```

### 2. Configure Backend

```bash
cd backend
cp .env.example .env
```

Edit `backend/.env` and set a **strong random string** for `JWT_SECRET`:

```env
JWT_SECRET=your-strong-random-secret-here
# Optional: explicitly opt in to sending journal text to OpenAI
ALLOW_EXTERNAL_AI=false
OPENAI_API_KEY=sk-...
```

### 3. Start the API

```bash
cd backend
npm run dev
# → http://localhost:4000
```

### 4. Start the Frontend

```bash
cd frontend
npm start
# → http://localhost:3000
```

## 📁 What to Upload to GitHub (Public) vs Keep Private

### ✅ SAFE TO UPLOAD TO GITHUB — Include in commits

| File / Folder | Reason |
|---------------|--------|
| `frontend/src/` | All source code — no secrets |
| `backend/src/` | All backend source code — no secrets |
| `frontend/public/` | Static assets (HTML, favicon, images) |
| `frontend/package.json` | Dependencies manifest |
| `backend/package.json` | Dependencies manifest |
| `frontend/tailwind.config.js` | Tailwind configuration |
| `frontend/postcss.config.js` | PostCSS configuration |
| `backend/.env.example` | Environment template (no real secrets) |
| `frontend/.gitignore` | Git ignore rules |
| `backend/.gitignore` | Git ignore rules |
| `.gitignore` | Root Git ignore rules |
| `README.md` | This file |
| `frontend/README.md` | Frontend docs |
| `backend/README.md` | API docs |

### ❌ DO NOT UPLOAD — Keep private / Add to .gitignore

| File / Folder | Reason |
|---------------|--------|
| `backend/.env` | Contains **JWT_SECRET** and **OPENAI_API_KEY** — these are your security credentials |
| `frontend/.env` (if created) | Contains API endpoint overrides |
| `node_modules/` | Auto-installed via `npm install` — too large, not needed in repo |
| `backend/data/aks-rooh.db` | SQLite database contains **user data (emails, password hashes, journal entries)** |
| `backend/data/` | Entire data directory (may contain `.db` and `.db-wal` / `.db-shm` files) |
| `frontend/build/` | Production build output — generated by `npm run build` |
| Any `*.log` files | Debug/error logs may contain sensitive info |

### ☁️ Cloud Deployment Notes

| Service | What to Deploy | Notes |
|---------|---------------|-------|
| **Frontend** | `frontend/build/` (after `npm run build`) | Deploy to Vercel, Netlify, Cloudflare Pages, or S3 |
| **Backend** | `backend/` (minus `node_modules`, `.env`, `data/`) | Deploy to Railway, Render, Fly.io, or a VPS |
| **Database** | `backend/data/aks-rooh.db` | **Private** — keep on server only, never upload to GitHub |
| **Environment** | Set env vars in your cloud dashboard | Never commit `.env` — set `JWT_SECRET`, `OPENAI_API_KEY` etc. in your hosting platform |

### 🔐 Security Checklist

- [ ] `JWT_SECRET` is a **long random string** (use `openssl rand -hex 32` to generate one)
- [ ] `backend/.env` is in `.gitignore` and never committed
- [ ] `ALLOW_EXTERNAL_AI` is `false` unless external processing is explicitly approved
- [ ] `OPENAI_API_KEY` (if used) is only in your server environment, never in client code
- [ ] The database file `aks-rooh.db` is in `.gitignore` and never uploaded
- [ ] Password minimum length is 8 characters (enforced by Zod validation)
- [ ] All API routes except `/api/auth/register` and `/api/auth/login` require authentication
